# Control schemes

Dango includes three selectable inspector schemes in Settings:

- **Legacy** — the original control layout.
- **Modern** — the modern workspace with optional experimental Transform and Color controls.
- **Neo** — the iOS-inspired grouped inspector, using the modern Transform and Color controls by default.

The preview canvas, title overlays, and text-box manipulation are fitted to the active project's selected aspect ratio.
